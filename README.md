# market-dashboard

A static market dashboard: `index.html` (YTD Dashboard), `longterm.html`
(Long-Term Summary), and `hyperscaler-capex.html` (Hyperscaler Capex), backed
by `fetch_data.py`.

The "Vol & Options" nav entry links to a separate Streamlit app
(`https://market-vol-dashboard.streamlit.app`) that lives in its own repo —
it is embedded here only as an external link, not rendered as part of this
site.
